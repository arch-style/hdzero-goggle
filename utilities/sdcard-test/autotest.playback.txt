# 再生機能の総点検 (約 4 分、見ているだけでよい。イヤホンがあれば D の音も)。

# 終わると ピッ・ピッ・ピッ・ピー。
#
#   A 再生開始の表示切り替え: メニュー(1080p50) → 720 行、720 → 1080 行 (いったん
#     720 に切り替えてから 1080 に切り替え直す)、1080 → 720、同じ 720 のまま次の
#     ファイル。どれも切り替えの間は黒で、ズレた画面が見えないこと。ログの
#     "playback: panel on after" と "UI layer window now" の順番、各回の grab で確かめる
#   B 操作 (720p60 HEVC): 止める、コマ送り・戻し、1s/5s/10s/30s の送り・戻し、
#     再開、1/2・1/4・1/8 速度、右ボタンのメニューを開いて閉じる
#   C 端: 先頭で戻す、末尾を越える送り (最後のコマ)、終端で送る・戻す
#   D 形式: H.264 TS、640x360、mp4 (H.264 + 音)、アナログ録画 (HEVC)
#   E HDMI の録画: 1080p60 (途中へ送る)、1080p50、720p 100fps (ラベルは 90)
#   F 1 秒未満のファイル
#   G 最後にメニューへ戻る (戻る切り替えの間も黒で、メニューが小さく出ないこと)
#
