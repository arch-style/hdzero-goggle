# 60Hz 再生で「ある明るさ（灰色の真ん中あたり）の画素だけ」が化ける件（約 1 分半）。
# 前回の写真: 蛍光灯まわりの点線もカラーバーの縦線も、出力の明るさ 128 (0x80) の
# 等高線だった。FPGA のライブ側は SoC の出力を OSD として重ねていて、黒を透明色として
# 抜いている（OSD の黒い背景に 0x010101 を使っているのはそのため）。その判定が 128 にも
# 当たっているらしい。
#
# 画面は keytest.ts（明るさの帯 6 本、左端に番号 1〜6）を止めたもの。
# バーの 2 行目 [ ] の英字ごとに写真を 1 枚ください。見るところ:
#   帯 1〜3 に縦線が何本あるか・どこか（1 は色なし、2・3 はほんの少し色つき）
#   帯 4〜6 に縦線や黒い点・色の点がないか
#
#   REF 50Hz menu   メニューと同じ 50Hz。縦線は出ないはず（比較用）
#   A 84=11 now     60Hz、今のまま（帯 1 と 4 に縦線が出るはず）
#   B〜H            OSD を重ねるやり方を決めているらしいレジスタ 0x84 の別の値
#   I 84=01         OSD を消す（真っ黒になれば正常）
#   J 8c=04 / K 8c=02   ライブ側の入力を HDMI 入力 / AV 入力に切り替えたときの重ね方
#   L back          元に戻す
# 画面が崩れる英字があっても、次の英字で戻ります。
size frame

echo dump on the menu
fpga dump
mem 0x06542000 64

pbdisplay 50
open /mnt/extsd/keytest.ts
wait 1500
pause
label REF 50Hz menu
wait 6000
exit
wait 1000

pbdisplay 60
open /mnt/extsd/keytest.ts
wait 1500
pause
echo dump at 60Hz
fpga dump
mem 0x06542000 64

label A 84=11 now
wait 6000
label B 84=10
fpga 0x84 0x10
wait 5000
label C 84=13
fpga 0x84 0x13
wait 5000
label D 84=15
fpga 0x84 0x15
wait 5000
label E 84=19
fpga 0x84 0x19
wait 5000
label F 84=31
fpga 0x84 0x31
wait 5000
label G 84=51
fpga 0x84 0x51
wait 5000
label H 84=91
fpga 0x84 0x91
wait 5000
label I 84=01 osd off
fpga 0x84 0x01
wait 5000
fpga 0x84 0x11

label J 8c=04 hdmi side
fpga 0x8c 0x04
wait 5000
label K 8c=02 av side
fpga 0x8c 0x02
wait 5000
fpga 0x8c 0x01
label L back
wait 4000
exit
label
